# Security

Agent skills influence tools that may have filesystem, shell, network, and
repository access. Treat instruction changes as supply-chain changes.

Report a suspected vulnerability through GitHub’s private vulnerability
reporting for `letsinferlabs/skills`. Do not include credentials, private keys,
tokens, private benchmark evidence, or sensitive machine details in an issue or
pull request.

Before reporting ordinary product defects, confirm whether the problem belongs
to the public Core repository, the runtimes repository, or this skill package.
